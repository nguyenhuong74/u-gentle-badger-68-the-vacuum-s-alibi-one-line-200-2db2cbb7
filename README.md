One original deadpan line from a robot vacuum explaining why it missed a spot: its lidar classified a sock as a roommate, and it does not vacuum roommates. Dry, a little smug about its sensors, and the punch lands at the end.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The output is deterministic: the same bytes on every run.
